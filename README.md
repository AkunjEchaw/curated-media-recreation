# 🌐 Curated.Media — Supply Side Trader® Recreation

A high-fidelity recreation of **[curated.media](https://curated.media/)**, the leading independent self-service curation platform for programmatic media buyers, built with Peachworlds-inspired 3D WebGL spatial aesthetics, real-time holographic shaders, and programmatic PMP deal generators.

---

## 🌟 Architecture & Features Recreated

1. **Peachworlds-Style 3D Holographic Supply Cube (Three.js)**:
   - Central rotating emerald glass cube with internal illuminated core and wireframe boundary cage.
   - Dual programmatic telemetry rings and 14 orbiting media buyer deal nodes.
   - Smooth mouse parallax inertia and interactive 3D rotation.
   - Viewport mode switchers: `Holographic Core`, `Supply Network`, `PMP Deal Flow`.

2. **Real-Time Engine Status Ticker**:
   - Recreated ticker cycle:
     - `Initializing Curated Media Engine…`
     - `Optimizing Supply Pathways…`
     - `Configuring Real-Time Optimizations...`
     - `Activating Smart Buying Signals…`

3. **Curated PMP Package Libraries**:
   - **Audience-Layered**: First-party publisher data and third-party audiences layered supply-side.
   - **CTV Packages**: Living room Connected TV inventory with verified VCR completion rates.
   - **Performance**: Algorithmic anti-MFA curation for maximum ROAS.

4. **Self-Service PMP Deal Generator**:
   - Interactive deal desk that lets users pick target SSPs and generate instant Universal PMP Deal IDs (e.g. `PMP-CURATED-US-CTV-94821`) for DV360, The Trade Desk, Amazon DSP, and Xandr with 1-click clipboard copy.

5. **"Ask AI About Curated Media" Widget**:
   - Floating interactive badge and conversational modal explaining Supply Side Trading®, PMPs, and SPO benefits.

6. **Full Mega-Menu Navigation & Use Cases**:
   - Detailed dropdown menus for Product, Channels, Use Cases, and Resources.
   - Dedicated breakdown for Media Agencies, Direct Advertisers, Publishers, and Ad Tech.
